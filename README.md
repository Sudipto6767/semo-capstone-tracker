# SEMO Capstone Project Tracker

## Team Members

- Sudipto Debnath

## Project Abstract

The SEMO Capstone Project Tracker is a web-based application designed to help students and faculty organize and explore capstone projects from previous semesters. The system will allow users to search and manage project information, making it easier for students to discover previous capstone projects and for the department to maintain an organized record of capstone work.
